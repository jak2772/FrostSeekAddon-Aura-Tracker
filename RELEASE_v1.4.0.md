# FrostSeek Aura Tracker v1.4.0

Major FrostSeek raid-setup workflow update.

- Replaces the old coverage rows with three live five-player raid-group panels.
- Displays player name, level, inferred role, and Aura assignment on each slot.
- Uses the Aura of Experience spell icon for every player: bright when enabled, grey when disabled.
- Clicking the icon toggles that player's Aura-provider assignment.
- Group headers show compact live coverage state.
- Adds roster posting, ready-check, and advisory group optimization actions.
- Adds an inline party/raid chat composer.
- Preserves the existing Aura sensors, provider inference, recruitment parsing, combat-role evidence, alerts, and five-second Manastorm entry audit.

The layout and workflow are an original FrostSeek implementation informed by raid-leader workflow testing; no third-party UI code or artwork is redistributed.

Requires [FrostSeek 2.2.5 or newer](https://github.com/ayro-CMD/FrostSeek).
