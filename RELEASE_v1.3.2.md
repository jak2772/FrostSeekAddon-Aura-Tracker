# FrostSeek Aura Tracker v1.3.2

Small UI readability and recruitment customization update.

- Shortens the recruitment checkboxes to `Auto-invite` and `Auto follow-up`.
- Condenses warnings, for example: `P2/P3 provider unverified.`
- Turns the recruitment preview into an editable outgoing message field.
- Adds `Use Auto` to restore the coverage-aware generated advert.

Requires [FrostSeek 2.2.5 or newer](https://github.com/ayro-CMD/FrostSeek).
