# FrostSeek Aura Tracker v1.4.1

UI clipping and readability hotfix for the v1.4 raid setup board.

- Separates the recruitment description from candidate headings.
- Moves raid chat into the wider recruitment-controls row.
- Restores clear spacing around alert toggles.
- Hides unused candidate scrollbars and empty-slot Aura icons.
- Keeps automatically generated recruitment messages scrolled to their beginning.
- Uses the correct bundled Aura of Experience Bonus XP icon on raid members.

Requires [FrostSeek 2.2.5 or newer](https://github.com/ayro-CMD/FrostSeek).
