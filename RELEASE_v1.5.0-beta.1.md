# FrostSeek Aura Tracker v1.5.0-beta.1

Non-live verification build for the v1.5 development line.

This package establishes the complete v1.5 workflow verification baseline. It includes:

- Correct bundled Aura of Experience Bonus XP artwork.
- A FrostSeek-styled Setup, Waiting, Raid, Run, and Rebuild workspace.
- Roster targets, applicant corrections, reservations, invitations, releases, and rejection handling.
- Three live raid-group cards, clickable Aura assignments, stepwise subgroup optimization, Ready Check, and roster posting.
- Guarded Manastorm Level 1 start, persistent rebuild recovery, reinvites, and Post & Leave controls.
- Editable recruitment, roster, level-59, level-60, and leave messages.
- Minimap access plus the existing Aura sensing, provider assignment, combat-role inference, alerts, and overlay.
- Complete custom FrostSeek input fields and corrected Alert-panel bounds.

Please test every protected raid action in a real raid before this build is promoted. Actions that depend on asynchronous roster changes intentionally advance one step per click.

Requires [FrostSeek 2.2.5 or newer](https://github.com/ayro-CMD/FrostSeek).
